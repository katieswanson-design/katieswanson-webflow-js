# Design tokens — katieswanson.design

Rebuilt 2026-09-09. Ramps generated by interpolating in OKLCH for perceptual
evenness, pinned to the values already in use so nothing on the site shifts
unless noted. Every step's contrast is verified against white and against
`navy/900`, the dark-mode surface.

`·` = pinned, unchanged from what the site already used. `NEW` = generated.

## Collection structure

Modes are per-collection in Webflow, and each layer needs a different mode axis.
That constraint sets the structure:

| Collection | Modes | Holds |
|---|---|---|
| `primitives` | none | raw ramps — nothing binds to these directly |
| `color` | Light · Dark | semantic colour roles, aliases only |
| `typography` | role modes (H1…) | families, weights, sizes, rhythm |
| `space` | none | spacing, radius, grid, containers |

## Colour roles

Two modes: **Light** and **Dark**. Every value is an alias to a primitive —
nothing holds a raw hex, so switching modes re-points references rather than
re-entering colour.

`text/tertiary` is **600, not 500** — `neutral/500` is 3.12:1 and fails AA for
body text. That pushed `text/secondary` to 700. Three distinct weights, all
passing, which matters now that the site carries writing.

| Role | Light | Dark | Note |
|---|---|---|---|
| `border/subtle` | neutral/200 | navy/800 | decorative dividers only |
| `border/interactive` | neutral/500 | navy/700 | **3:1 — inputs, controls** |
| `border/inverse` | neutral/50 | navy/900 | |
| `border/accent` | emerald/400 | emerald/400 | |

**Non-text UI needs 3:1, not 4.5.** `neutral/200` on white is 1.27:1 — fine for a
divider, not acceptable as the only indicator of a form field boundary.
`neutral/500` (3.12:1) is the first step that passes. Hence the split.

## Notes

- Roughly 18 of the 33 primitives are consumed by a semantic role today. The
  remainder (navy 200–600, emerald 600–950 below the accent pair) is deliberate
  headroom — a ramp with holes invites ad-hoc additions, which is how the
  previous token set drifted.
- Nothing binds to a primitive directly. Styles bind to semantic roles only.
- Contrast figures are WCAG 2.1 relative luminance. AA = 4.5:1 normal text,
  3:1 large text and non-text UI. AAA = 7:1.
